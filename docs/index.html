Technical Preview

Install with
your eyes open.

This preview is ad-hoc signed and not notarized by Apple. macOS may block the first launch. Review the source and proceed only if you are comfortable testing pre-release software.

Get v0.1.0 ↓
  1. 01

    Download and mount

    Download the DMG from GitHub Releases, open it, and drag M4 Companion to Applications.

  2. 02

    Open explicitly

    In Applications, Control-click or right-click M4 Companion, choose Open, then confirm Open.

  3. 03

    If macOS still blocks it

    Open System Settings → Privacy & Security, find the blocked-app notice, and choose Open Anyway.

Optional Terminal method +
Terminal
xattr -dr com.apple.quarantine "/Applications/M4 Companion.app"

Only remove quarantine after you have verified the download and trust its source.
